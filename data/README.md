# Reproducible scan / height summaries

The full `k(n)` table for `n ≤ 10⁷` is a 10 MB byte array and is regenerated by

```bash
python -m es_agent.cli scan --n-max 10000000 --out data/scan_1e7.json
```

The small JSON files checked in here are sufficient to reproduce the headline
numbers and the figures:

| file | content |
|---|---|
| `scan_2e7.json` | distribution and records for `n ≤ 2×10⁷` |
| `records_1000000.json` | record list for `n ≤ 10⁶` |
| `heights_1000000.json` | top heights and counts for `n ≤ 10⁶` |

The authoritative run artefacts (trace, certificates, figures) are in
`runs/main/`.
